# ⚡ Pikachu

A fun and interactive web experience featuring everyone's favorite electric Pokémon! This project brings Pikachu to life with playful cursor interactions and eye-catching visual effects.

Move your cursor around the screen and watch Pikachu's eyes follow your every movement. Click on Pikachu to unleash a burst of electric sparks across the screen, creating a satisfying and engaging animation.

Built to practice animations, event handling, cursor tracking, and interactive UI development using modern web technologies.

## 🌐 Live Demo

👉 https://pikachuuuuuu.netlify.app/

## ✨ Features

- ⚡ Pikachu's eyes follow your cursor in real time.
- 👀 Smooth mouse tracking animation.
- ✨ Clicking Pikachu creates electric spark effects across the screen.
- 🎨 Cute and interactive UI.
- 📱 Fully responsive design.
- ⚡ Fast performance with smooth animations.
- 🎮 Fun and engaging user interaction.

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/spidey0-45/pikachu.git
```

Navigate into the project

```bash
cd pikachu
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```
